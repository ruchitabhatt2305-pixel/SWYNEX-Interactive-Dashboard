# SWYNEX-Interactive-Dashboard
# Superstore Sales Dashboard Using Tableau

## Project Overview
This project focuses on creating an interactive sales dashboard using Tableau with the Sample Superstore dataset. The dashboard helps analyze sales, profit, orders, discounts, and business performance.

## Objectives
- Analyze overall sales and profit.
- Compare sales across different categories and regions.
- Identify monthly sales trends.
- Analyze sales by state and sub-category.
- Create an interactive dashboard using filters.

## Tools Used
- Tableau
- Microsoft Excel
- Sample Superstore Dataset

## Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Average Discount
- Sales by Category
- Profit by Region
- Monthly Sales Trend
- Sales by State
- Sales by Sub-Category

## Interactive Filters
- Region
- Category
- Segment
- Order Date
- Ship Mode

## Key Learnings
- Connecting Excel datasets to Tableau.
- Creating KPI cards and charts.
- Using filters and interactive dashboards.
- Analyzing sales and profit trends.
- Presenting business insights through data visualization.

## Conclusion
This project helped me understand how Tableau can be used to analyze business data and create interactive dashboards for better decision-making.
